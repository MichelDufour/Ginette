# Ginette Pantoufle (parodie)

Site public de [@GinettePantouf](https://x.com/GinettePantouf), compte parodique sur X :
caricatures, posts de Ginette et ses réponses avec la source.

- `index.html` : la page (elle lit `journal.json`).
- `journal.json` : les caricatures publiées seulement.
- `images/` : les caricatures.
- `outils/publier.py` : met à jour `journal.json` et `images/` à partir du journal privé.
- `deploiement/installer.sh` : installation sur le serveur (Caddy, mise à jour aux 10 minutes).

Ginette et Réal sont des personnages inventés. Les faits publics cités sont réels et sourcés.
